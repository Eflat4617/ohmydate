# 01. 제품 요구사항 (PRD) — 가칭 OhMyDate Adaptive Planner

> 작성: 2026-11-11, Opus 5.5 오케스트레이터 (Phase D0, 읽기 전용 설계)
> 기준: `ORCA_ADAPTIVE_PLANNER_MASTER_SPEC.md` §2, §5–§7, §11
> 표기: **[확인]** 근거 있음 · **[가정]** 되돌릴 수 있는 임시 결정 · **[결정]** ADR로 확정 · **[미결정]** 승인 게이트 필요

## 1. 제품 한 줄 정의

목표를 등록하면 맥락을 수집하고, 작업을 분해하고, **실행 가능한 서로 다른 일정안**을 제시하며, 사용자가 승인한 일정만 반영하고, 실제 수행 시간으로 점진적으로 개인화·재계획하는 **폐회로 개인 플래너**.

폐회로: `목표 등록 → 맥락 수집 → 작업 분해 → 계획 생성 → 사용자 승인 → 일별 수행 → 실제 시간 확인 → 개인화 → (필요 시) 재계획`

## 4. 필수 사용자 시나리오와 수락 기준

### A. 처음 등록하는 유형의 과제
1. 과제명·마감·설명·파일 등록 → `IntakeSession` 생성.
2. 유형 판정: `new | similar(templateId, confidence, reasons[])`.
3. 신규/정보 부족 시 **동적 인터뷰**: 이미 제공된 필드는 묻지 않음. 질문 상한 기본 5개/라운드, 2라운드 [가정].
4. 단계·하위 작업·선후관계·추정 구간(P50/P90)·검수/버퍼 제안.
5. 스케줄러가 3개 정책으로 실행 가능한 후보 생성. 불가능하면 가능한 개수와 사유(`deficitMinutes` 등).
6. 비교 화면에서 선택·편집·확정 전에는 실제 일정 미변경.
7. 확정 시 ScheduleBlock + 알림 예약.

**수락 기준 (AC-A):** ① 이미 입력된 필드에 대한 질문 0건 ② "건너뛰기/직접 작성" 항상 가능 ③ 후보 모두 하드 제약 위반 0 ④ 승인 전 `schedule_block` 변경 0 ⑤ 승인 요청은 멱등(같은 키 재전송 시 동일 결과).

### B. 과거와 유사한 과제
- 유사 템플릿 후보 + 근거(태그/프로젝트/임베딩 없이 시작하는 텍스트 유사도/과거 실측) 표시 → "이전과 같은 유형인가요?" 확인 → 아니오면 A로.
- 예이면 과거 단계 구성·실측 시간 제시 + **차이 질문**(이번에 달라진 요구사항). 템플릿 강요 금지.

**AC-B:** 오탐 교정 시 해당 fingerprint 신뢰도 하향 기록, 다음 판정에 반영.

### C. 일일 실행 및 체크인
- Today: 기본 2–3개 작업(설정 가능), 수락/축소/재배치.
- Focus 세션: 시작/일시정지/재개/완료, `focusedMinutes`와 `elapsedMinutes` 분리.
- 종료 피드백: 1탭 선택지(완료/부분/미완) + 선택적 사유 칩.
- 추정 갱신은 즉시 반영하되 **재계획 제안은 위험/충돌 발생 시에만**.

**AC-C:** 세션 중복 시작 불가(한 사용자 동시 active 세션 1개), 알림 중복 0(dedupe 키), 하루 재계획 제안 상한 기본 2회 [가정].

### D. 노트·참고문서 맥락
- Markdown 노트, 링크, 첨부(이미지/PDF), 체크리스트, 결정 기록을 Goal/Project/Task에 연결.
- AI는 관련 문서만 선택해 사용하고 **사용한 근거(문서·구간)를 표시**.
- 거대 블록 에디터 제작은 비목표. Markdown 에디터 + 미리보기로 시작.

### E. 적응형 레이아웃
- 상태: `overview | planning | focus | deadline_risk | review | notes`.
- 사용자 패널 고정/수동 배치/자동 전환 끄기 지원. 자동 전환 hysteresis(기본 최소 10분 유지 [가정]).
- AI는 **레이아웃 JSON**만 제안, 허용 컴포넌트만 렌더.

### F. 장기 계획/공모전 (M8+, MVP 제외)
- rolling-wave: 먼 미래는 마일스톤, 가까운 1–2주만 상세 블록.
- 외부 검색/스크래핑의 합법성·약관·출처 검증은 별도 요건. **MVP 미구현.**

## 6. 비목표 (Non-goals)

초기 다중 사용자 협업, 결제/청구, 자체 LLM 학습, 거대한 문서 에디터, 실시간 음성 에이전트, 공모전 자동 등록/제출, 네이티브 모바일 앱(PWA로 검증 후 재판단), 오프라인 편집 큐(M8 재평가, ADR-010).

## 7. 성공 지표 (모두 [초기 목표/가정], M4 이후 실측으로 재조정)

| 지표 | 초기 목표 | 선택 이유 |
|---|---|---|
| 하드 제약 위반 | 0 (property test 10k 케이스) | 신뢰의 전제, 타협 불가 |
| 3안 생성 지연 | p95 < 2s (작업 ≤ 50, 기간 ≤ 14일, 홈서버) | 비교 화면 체감 |
| 계획 승인율 | ≥ 60% (편집 후 승인 포함) | 후보 품질 대리지표 |
| 제때 완료율 | 기준선 측정 후 +10%p | 기준선 부재 |
| 추정 오차 | MAPE 4주 후 ≤ 35% | 개인 데이터 축적 후 개선 기대 |
| 재계획 제안 | 주 ≤ 3회, 거절률 < 50% | 알림 피로 |
| 인터뷰 질문 수 | 신규 유형 평균 ≤ 6, 유사 유형 ≤ 3 | 부담 최소화 |
